# Coração de partículas ❤️

Animação interativa feita com HTML, CSS e JavaScript puro. Não precisa de dependências nem de etapa de build.

## Executar localmente

Abra `index.html` no navegador.

## Publicar no GitHub e Vercel

1. Crie um repositório no GitHub (por exemplo, `coracao-de-particulas`).
2. Envie `index.html` e `README.md` para a raiz do repositório.
3. No Vercel, escolha **Add New → Project** e importe o repositório do GitHub.
4. Em **Framework Preset**, escolha **Other** (ou deixe sem framework, se essa opção aparecer).
5. Deixe **Build Command** e **Output Directory** vazios. Não é necessário comando de build.
6. Clique em **Deploy**.

O Vercel detecta e publica o `index.html` como um site estático.
